# Better Sidebar (`agy-better-sidebar` v2.0 · Typora Lapis 沉浸纸感版)

复刻 **Typora + `typora-theme-lapis`（青金石）** 极简纸张美学与学术排版体验的 Antigravity 官方插件。

## 核心亮点
- **真·Typora 极简无框骨架（Chromeless Paper UI）**：
  - 92%+ 画面留给通透的 `#write` 阅读纸面，砍掉繁重的多层工业工具栏与底栏；
  - 左侧合并为正统 Typora 风格的 **「最近 | 文件 | 大纲」三合一极简抽屉**（点击大纲可在排版预览中直接平滑滚动至对应标题，无需切回源码）。
- **默认搭载 Lapis 青金石学术主题 + 四套经典主题一键切换**：
  - 内置 **Lapis 青金石（默认：清透湖蓝 + 胶囊二级标题） / GitHub 极简白 / Newsprint 暖纸书卷 / Lapis Night 柔和暗夜**。
- **科研宽表格专项优化（支持一键切换「学术三线表」）**：
  - 专为多列路线图与检索表设计防挤碎平滑横滑容器，Markdown 表格与 CSV/TSV 数据表共享 **「圆角斑马卡片表 ↔ 论文标准学术三线表」** 一键切换。
- **零额外费用 AI 伴读**：
  - 右上角轻巧 **「✨ AI 伴读」下拉胶囊** + **正文/代码划词悬浮气泡**（大白话解读、生成流程图、逐段导读、引用提问，支持切换发往后台新对话）。
